              Passo a passo da configuração
              
    
              Faça uma vez só, no computador. Leva de 30 a 40 minutos.
              

    
              
      1. Colocar a página no ar (GitHub Pages)
      
                
        
              1. Crie uma conta grátis em github.com.
                2. 
        
              2. Clique no + no alto → New repository. Nome: rlmotoboy, deixe Public, marque Add a README file e clique em Create repository.
                3. 
        
              3. No repositório, Add file → Upload files, arraste o arquivo index.html e clique em Commit changes.
                4. 
        
              4. Vá em Settings → Pages. Em Branch, escolha main e /(root) e clique em Save.
                5. 
        
              5. Em 1 ou 2 minutos aparece o endereço: https://SEU-USUARIO.github.io/rlmotoboy/. Use sempre esse endereço.
                6. 
      
              
      
              O arquivo não tem nenhuma chave dentro: as chaves você cola aqui na página, então pode ficar público.
              
    
              

    
              
      2. Criar a chave do Google
      
                
        
              1. Entre em console.cloud.google.com e crie um projeto chamado RL Motoboy.
                2. 
        
              2. Faturamento: no menu, Faturamento → vincule uma conta com cartão. O Google exige, mesmo dentro do uso gratuito.
                3. 
        
              3. APIs e serviços → Biblioteca: procure e ative Places API (New) e Routes API.
                4. 
        
              4. APIs e serviços → Credenciais → Criar credenciais → Chave de API.
                5. 
        
              5. Abra a chave criada e proteja:
          
                  
            
                • Restrições de aplicativos: Sites → adicione https://SEU-USUARIO.github.io/*
                  • 
            
                • Restrições de API: Restringir chave → marque Places API (New) e Routes API.
                  • 
          
                
          Salve.
                6. 
        
              6. Recomendado: em Faturamento → Orçamentos e alertas, crie um alerta de R$ 10 para ser avisado se algo sair do normal.
                7. 
        
              7. Copie a chave, cole no campo Chave do Google desta aba e clique em Salvar e testar. As duas linhas precisam ficar verdes.
                8. 
      
              
    
              

    
              
      3. Ligar a nuvem (Firebase)
      
                
        
              1. Entre em console.firebase.google.com → Criar um projeto novo, com o nome rl-motoboy-dados. Use um projeto separado do da chave do Google: assim ele fica no plano gratuito (Spark), sem cartão. Pode desligar o Google Analytics.
                2. 
        
              2. Authentication → Vamos começar → Google: ative, escolha seu e-mail de suporte e salve. Depois, em Adicionar novo fornecedor, ative também o Anônimo (é o que deixa o motoboy entrar no chat da corrida pelo link).
                3. 
        
              3. Authentication → Configurações → Domínios autorizados → Adicionar domínio:  (o endereço do GitHub, sem https e sem /rlmotoboy).
                4. 
        
              4. Firestore Database → Criar banco de dados: local southamerica-east1 (São Paulo), modo de produção.
                5. 
        
              5. Na aba Regras do Firestore, apague tudo e cole as regras abaixo, com o seu e-mail do Google. Depois clique em Publicar.
          
          
                
          
        
                6. 
        
              6. Configurações do projeto (engrenagem) → Seus apps → ícone </> (Web) → apelido Central → Registrar app. Copie o bloco const firebaseConfig = { … }.
                7. 
        
              7. Cole o bloco em Nuvem (Firebase) nesta aba, clique em Conectar e entre com o mesmo e-mail das regras.
                8. 
      
              
      
              Só os e-mails das regras conseguem ver ou mudar os dados. Para liberar um funcionário, adicione o e-mail dele e publique as regras de novo.
              
    
              

    
              
      4. Usar no celular
      
                
        
              1. No celular, abra o endereço da Central no Chrome.
                2. 
        
              2. Toque em Entrar com Google, no alto, e entre com o mesmo e-mail do PC. A chave do Google e todos os cadastros vêm sozinhos.
                3. 
        
              3. No menu ⋮ do Chrome, toque em Adicionar à tela inicial para ter o ícone como um app.
                4.
