📱 Simulador de celular

É o mesmo sistema do app, do tamanho de um celular. O login aqui é o mesmo deste navegador: se você já está logado no painel, entra direto (use “🏍 Ver como motoboy”). Para ver como outra pessoa ao mesmo tempo, abra esta página numa janela anônima (Ctrl+Shift+N) e entre com outra conta.
